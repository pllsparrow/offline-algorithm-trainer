# 099. Climbing Stairs

- Chapter: 13. 1-D Dynamic Programming
- Difficulty: Easy
- Source: https://leetcode.com/problems/climbing-stairs/
- Reference: https://neetcode.io/problems/climbing-stairs?list=neetcode150

## Goal

Count the ways to reach the nth stair when you can climb 1 or 2 steps at a time. Practice 1D DP.

## Interview Focus

- Identify the core pattern: state definition.
- Before coding, state the invariant or state definition: transition equations.
- After it passes, explain the time complexity, space complexity, and one edge case.

## ACM Format

Input: n: an integer. Output: the integer.
